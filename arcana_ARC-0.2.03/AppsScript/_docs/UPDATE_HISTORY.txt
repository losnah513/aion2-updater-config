ARC-0.2.02

[이번 작업 요약]
- 앱스크립트 버전 상수를 ARC-0.2.02로 갱신했습니다.
- 클래스 목록을 시트명과 A1 클래스명을 기준으로 정리하도록 수정했습니다.
- 클래스 표시 순서를 수호성, 검성, 살성, 궁성, 마도성, 정령성, 치유성, 호법성 순서로 고정했습니다.
- 각 클래스 시트의 D1:I1과 그 아래 스킬 목록을 아르카나별 등록 가능 스킬 풀로 읽도록 수정했습니다.
- 초기 데이터에서 기본 검성 스킬을 내려보내지 않도록 수정했습니다.

[참고]
- skill_db_로 시작하는 시트를 클래스 DB로 인식합니다.
- D1:I1은 아르카나 종류입니다.
- D2:I 아래 영역은 각 아르카나에 등록 가능한 스킬 목록입니다.
