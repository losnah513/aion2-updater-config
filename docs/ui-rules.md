# KINOJO UI 유지보수 규칙

## 스타일 소유권

- 공개 페이지의 고정 상단바, 메뉴 드로어, 고정 공지바 위치·크기·반응형 규칙은 `ui/kinojo-public-shell.css`만 소유합니다.
- `ui/kinojo-common-ui.css`에는 로그인, 오류 안내, 공지 상세 등 재사용 부품만 둡니다. 공개 프레임 선택자를 이 파일에 다시 추가하지 않습니다.
- 관리자 페이지의 전용 상단바, 관리 메뉴, 대시보드 위치·크기·반응형 규칙은 `admin/css/admin.css`만 소유합니다.
- 같은 요소를 파일 아래쪽의 보정 규칙으로 재정의하지 않습니다. 변경이 필요하면 기존 소유 규칙을 직접 수정합니다.

## 선택 전환 규칙

- ON/OFF, 포함/제외, 허용/차단처럼 두 상태를 즉시 전환하는 기능은 레기온 랭킹의 부캐 포함/제외와 같은 슬라이드 스위치를 사용합니다.
- 저장이나 서버 반영이 별도로 필요하면 스위치 옆에 저장 상태를 표시하며, 일반 실행 버튼처럼 표현하지 않습니다.
- 단순 이동, 조회, 저장, 삭제 기능에는 슬라이드 스위치를 사용하지 않습니다.

## 화면 안전 영역

- 공개 메뉴와 모달은 `--kinojo-safe-top`, `--kinojo-safe-bottom` 사이에서만 열어 고정 상단바와 공지바를 가리지 않습니다.
- 모바일 관리자 메뉴는 대시보드의 정사각형 카드로 진입하고, 본문에는 현재 선택한 관리 영역만 표시합니다.
