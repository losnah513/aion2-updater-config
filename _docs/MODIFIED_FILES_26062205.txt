KINOJO WEB DEVICE ROUTING / MOBILE ROAD SPLIT
작업일: 2026-06-22

[공통 수정]
- GitHub_Pages/index.html: 루트 진입 라우터로 전환
- GitHub_Pages/home.html: 기존 PC 메인 보존
- GitHub_Pages/ui/kinojo-device-router.js: 모바일/PC 감지 및 페이지별 모바일 경로 이동 공통 스크립트 추가

[WEB]
- 기존 PC 페이지는 삭제하지 않고 유지
- home.html, hall-of-fame, sanctuary, arcana, pages 문서에 모바일 진입 스크립트 연결
- GitHub_Pages/desktop/: 명시적 PC 진입 경로 추가
- GitHub_Pages/mobile/: 모바일 전용 진입 폴더 추가

[ARCANA]
- 모바일 터치 불편 요소였던 더블터치/한 번 더 터치 확정 로직 제거
- 클래스 쇼케이스 선택은 1회 탭 기준으로 변경
- 추천 분석 버튼은 1회 탭 실행 기준으로 변경
- 클래스 입장 게이트 버튼은 1회 탭 실행/닫기 기준으로 변경
