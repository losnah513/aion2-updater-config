아르카나 스킬 시뮬레이터
버전: ARC-0.3.02

이 폴더는 GitHub Pages에 업로드하는 웹페이지 파일입니다.
Apps Script 파일은 별도 AppsScript 폴더에서 관리합니다.

실행 주소 예시:
https://kinojo.info/arcana/


[2026-06-20 통합 Shell 기준]
- ARCANA는 KINOJO GitHub Pages 내부 페이지로 편입된 상태입니다.
- 탑바/메뉴바/로그인/관리패널/로딩 스피너는 KINOJO 공통 Shell을 사용합니다.
- ARCANA 전용으로 유지하는 영역은 시뮬레이터 로직, 카드 배치, 아르카나 전용 애니메이션입니다.
- 공통 UI를 수정할 때 ARCANA 내부에 별도 메뉴/로그인/스피너를 중복 추가하지 않습니다.
