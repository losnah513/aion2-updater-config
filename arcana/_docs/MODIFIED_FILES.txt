[수정 내용]
1. 렌더링 안정화
- renderAll()을 단일 진입점으로 유지하되 모듈별 try/catch 보호를 추가했습니다.
- 한 영역 렌더 실패가 전체 앱 이벤트 바인딩 중단으로 이어지지 않도록 했습니다.

2. 현재 아르카나 렌더링 복구
- 누락되어 있던 cardEditor.createOwnedCard()를 복구했습니다.
- 현재 아르카나 카드가 항상 arcanaTypes 기준으로 렌더링되도록 정리했습니다.

3. 저장/수정 상태 안정화
- 저장 후 '수정하기' 버튼이 다시 비활성화되는 문제를 수정했습니다.
- 저장 버튼 바인딩에 null guard를 추가했습니다.
- 저장된 보유 아르카나/반지/액티브 선택 데이터를 초기화 시 무조건 비우지 않도록 hydrateSavedState()로 통합했습니다.

4. 상태관리 정리
- selectedTargetSkills, targetSkillLevels, activeSkillTargets, ownedCards, equipmentOptions/ringOptions, recommendationResult를 단일 초기화 흐름으로 정리했습니다.
- 클래스 변경 시 클래스 의존 상태와 localStorage 저장값을 함께 초기화하도록 정리했습니다.

5. 이벤트 시스템 정리
- 앱 이벤트 바인딩 중복 방지를 추가했습니다.
- 클래스 선택 긴급 임시 캡처 이벤트와 부트 가드를 제거하고 일반 바인딩 흐름으로 통합했습니다.

6. CTA 안정화
- SVG 파동 CTA 생성은 buildCtaVisualizer() 단일 함수로 유지했습니다.
- 추천 계산 중 오류 발생 시 버튼이 loading 상태에 갇히지 않도록 try/finally 처리했습니다.
