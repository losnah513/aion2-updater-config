ARC-0.1.00 수정사항 3

[이번 작업 요약]
- 선택된 버튼과 마우스 올림 효과를 분리했습니다.
- 선택된 버튼에는 테두리를 따라 도는 빛과 내부 물결 효과를 추가했습니다.
- 클래스 변경 시 이전 클래스에서 저장되어 잠긴 창 상태가 풀리도록 수정했습니다.
- 장비 선택에서 새 장비를 추가할 때 기존 장비 카드가 다시 열리는 것처럼 보이지 않도록 정리했습니다.
- 페이지와 각 항목의 폭을 내용 기준으로 더 압축했습니다.
- 클래스 선택 버튼의 문자를 직접 기호로 쓰는 방식에서 아이콘 느낌의 표시 방식으로 변경했습니다.
- 탑바 왼쪽에 메뉴 버튼과 관리자 추가 버튼을 분리해 배치했습니다.
- 액티브 스킬 선택 개수 안내는 평소에는 통일 색상으로 표시하고, 초과 클릭 시에만 붉게 강조되도록 수정했습니다.
- 현재 캐릭터 스킬 레벨 입력칸을 스킬명 옆에 더 붙여 배치했습니다.
- 아르카나와 장비 스킬 선택 드롭다운을 웹페이지 스타일의 커스텀 드롭다운으로 변경했습니다.
- 긴 스킬 목록은 6줄까지만 보이고 내부 스크롤로 이동하도록 수정했습니다.

[참고]
- Apps Script 소스 수정은 없습니다.
- 이번 작업은 화면 구성, 버튼 반응, 드롭다운 표시 방식 중심의 수정입니다.
- customSelect.js 파일이 새로 추가되었습니다.
