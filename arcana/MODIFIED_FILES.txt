[수정 내용]
1. CTA 기본 상태 속도 보정
   - idle 방사형 막대 파동 속도를 기존 대비 절반 수준으로 완화.
   - 기본 상태는 흑백/저강도 상태를 유지.

2. CTA 롤오버 상태 보정
   - hover 상태는 단색 블루 계열 유지.
   - hover 속도는 이전 체감 속도 수준으로 유지.
   - 다채로운 색상 변화는 hover가 아니라 분석중 상태에서만 사용.

3. CTA 분석중 색상 전환 보정
   - 클릭 즉시 컬러로 확 바뀌지 않도록 stroke/filter transition 추가.
   - loading 상태에서 단색 → 보라/핑크/블루/민트 계열로 부드럽게 흐르는 컬러 애니메이션 추가.
   - 최소 분석 유지 시간 5.2초 기존 유지.

4. CTA 뒤 기본 안내 문구 제거
   - 추천 CTA 뒤에 남던 기본 안내 텍스트 제거.
   - 기본 메시지는 숨기고, 실제 경고/완료/오류 상태 메시지만 표시하도록 조정.
