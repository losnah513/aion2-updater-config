# 배너 관리 리디자인 — 2단계 인계

기준일: 2026-08-24 KST
상태: 5단계 작성 화면·이미지 묶음 UI 완료

## 완료 범위

- 메인 배너와 사이드 배너에 같은 구조의 이벤트 작성 워크플로를 적용했다.
- 상단에 `이미지 추가 → 노출 묶음 → 이미지 이벤트 설정 → 문구 편집 → 검토·게시` 5단계 진행도를 배치했다.
- 이미지 추가는 별도 버튼과 파일 목록을 분리하지 않고 카드 자체를 추가 진입점으로 사용한다.
- 한 장을 선택하면 기존 카드를 유지한 채 다음 `이미지 추가` 카드가 자동으로 생긴다.
- 이미지가 3장이 되면 추가 카드를 제거하고, 추가 선택도 3장으로 제한한다.
- 한 번의 파일 선택 창에서 여러 장을 선택해도 남은 카드 수만큼 이어서 추가한다.
- JPEG·PNG·WebP 원본을 비율 변환 없이 업로드한다. 서버가 크기와 서명을 다시 검증한다.
- 각 카드에 원본 크기, 용량, 상태와 배너 비율 차이로 인한 잘림·확대 가능성을 표시한다.
- 업로드만으로는 게시되지 않으며, 성공한 이미지만 새 노출 묶음에 자동 선택한다.
- 노출 묶음은 기존 게시 이미지를 자동 상속하지 않고 빈 상태에서 새로 구성한다.
- 이미지 라이브러리에서 최대 3장을 추가·제거하고 위·아래 버튼으로 `1 → 2 → 3` 순서를 변경한다.
- 이벤트 이름과 최대 5개 해시태그 칩을 입력하고, 업로드 이미지의 해시태그로 라이브러리를 필터링한다.
- 3~5단계는 다음 구현 위치와 기능을 한 줄로 안내하며, 초안 저장·전체 게시 버튼은 아직 비활성화한다.
