ARC-0.1.00 UI 압축 테스트 3

[이번 작업 요약]
- 전체 배경과 카드 배경을 화이트 기준으로 정리했습니다.
- 카드 테두리의 둥근 정도를 줄이고, 키노조에 가까운 단정한 화면 톤으로 조정했습니다.
- 20레벨 목표 스킬 선택 영역 오른쪽에 현재 선택 개수 표시를 추가했습니다.
- 현재 캐릭터 스킬 레벨 입력창과 목표 스킬 선택창의 좌우 배치를 유지하면서 여백과 높이를 줄였습니다.
- 장비 스킬 옵션은 처음부터 모든 창을 펼치지 않고, 무기/가더/반지1/반지2 버튼을 눌렀을 때만 아래로 열리도록 변경했습니다.
- 장비 스킬 레벨은 입력칸 없이 Lv. 1 텍스트로만 표시하도록 바꿨습니다.
- 아르카나 카드 옵션은 현재 아르카나와 추천 아르카나를 좌우로 나누고, 각 영역 안에서 PC 기준 2카드씩 보이도록 정리했습니다.
- 저장 시 새창 알림 대신 해당 창 내부 안내 문구로 표시되도록 변경했습니다.
- 저장 완료 후에는 해당 창만 잠금 상태처럼 빗금 처리되며, 초기화 버튼만 강조되도록 변경했습니다.

[참고]
- 버전명은 ARC-0.1.00으로 유지했습니다.
- 이번 작업은 디자인과 화면 동작 정리 중심입니다.
