KINOJO GitHub Pages Reorganization Report
Version base: 1.c2.04
Date: 260616

[Purpose]
- 최근 KINOJO 파일을 GitHub 업로드용으로 재구성.
- ARCANA는 별도 작업물이므로 포함하지 않음.
- GitHub Pages 진입과 확장프로그램 원격 config 호환성을 유지.

[Root]
- index.html: GitHub Pages 루트 진입용 리다이렉트.
- config.json: 확장프로그램 원격 설정 호환용으로 루트 유지.
- README.md: 업로드 구조 안내.
- kinojo-main/: 메인 페이지, 공통 ui/core/pages/docs.
- hall-of-fame/: 명예의 전당 페이지와 전용 assets/css/js.
- sanctuary/: 성역 페이지와 전용 css/js.

[Changed Paths]
- GitHub_Pages/index.html -> kinojo-main/index.html
- GitHub_Pages/core -> kinojo-main/core
- GitHub_Pages/ui -> kinojo-main/ui
- GitHub_Pages/pages -> kinojo-main/pages
- GitHub_Pages/_docs -> kinojo-main/docs
- GitHub_Pages/hall-of-fame -> hall-of-fame
- GitHub_Pages/sanctuary -> sanctuary

[Code Path Fix]
- kinojo-main/index.html: hall-of-fame/sanctuary 링크를 상위 루트 기준으로 수정.
- kinojo-main/ui/info-home.css: 루드라 에셋 경로를 새 구조 기준으로 수정.
- hall-of-fame/index.html: 공통 UI/CSS 경로를 ../kinojo-main/ui/ 기준으로 수정.
- sanctuary/index.html: 공통 UI/CSS 경로를 ../kinojo-main/ui/ 기준으로 수정.
- kinojo-main/ui/kinojo-common-ui.js: Drawer 이동 경로를 새 루트 구조 기준으로 수정.

[Validation]
- 전체 JS node --check 통과.
- CSS url(...) 로컬 파일 참조 확인 통과.
- _docs 폴더명 제거, docs로 변경.

[Note]
- 루트 config.json은 확장프로그램이 기존 URL /config.json을 참조하므로 삭제하지 않음.
- 루트 index.html은 GitHub Pages 기본 진입을 위해 유지.
