ARC-0.1.00 수정사항 2

[이번 작업 요약]
- 초기 화면에서 클래스 선택 전에는 주요 입력 영역이 흐리게 비활성화되도록 변경
- 상단 고정 탑바 추가
- 관리자 메뉴 버튼 추가, 현재는 비활성화 상태
- 키노조 메뉴 이동 버튼 추가
- 클래스 선택을 기본 선택상자에서 버튼형 드롭다운 카드 구조로 변경
- 액티브 스킬 선택창 제목과 선택 개수 문구 동작 수정
- 스킬 7개 초과 선택 시 새 창 없이 제목 오른쪽 문구가 붉은색으로 반응하도록 변경
- 액티브 스킬 버튼 폭을 클래스 변경과 관계없이 고정 기준으로 계산하도록 변경
- 현재 캐릭터 스킬 레벨 영역 폭을 액티브 스킬 선택 영역과 맞춤
- 장비 선택 버튼과 장비 입력창 폭을 줄이고 병렬 배치가 되도록 조정
- 모든 스킬 레벨 입력칸의 숫자 화살표 제거
- 저장 후 초기화 버튼 테두리 빛 효과 강화
- 버튼 롤오버 반응 효과 추가
- 추천 아르카나 로딩 연출 시간을 조금 더 길게 조정
- 추천 아르카나 로딩 스피너와 문구가 창 중앙에 오도록 정렬 조정
- 새로고침 시 현재 화면 입력값이 초기화된다는 안내문구 추가

[참고]
- 이번 작업은 화면 구조와 디자인 중심 수정입니다.
- Apps Script 소스 파일은 교체하지 않아도 됩니다.
- 클래스별 스킬 시트는 skill_db_직업명영어 형식을 기준으로 읽습니다.
- 각 클래스 시트의 A1은 직업명, A3:A는 액티브 스킬, B3:B는 패시브 스킬 기준입니다.
