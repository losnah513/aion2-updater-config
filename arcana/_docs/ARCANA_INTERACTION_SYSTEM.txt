ARCANA INTERACTION SYSTEM
Version: ARC-0.3.02
Created: 2026-06-15

[관리 규칙]
- 이 문서는 ARCANA 인터랙션 규칙을 누적 관리한다.
- 작업마다 새 문서를 만들지 않고 이 파일 하단에 업데이트한다.
- 버튼/영역 카드 크기는 기존 기준본을 유지한다.
- 효과와 안내 로직은 담당 파일을 분리하고, 여러 파일에 조건문을 흩뿌리지 않는다.

[기본 인터랙션 규칙]
PC:
- Hover와 Click은 서로 다른 반응을 가진다.
- Hover는 예고/강조, Click은 실제 실행이다.

Mobile:
- 일반 버튼은 1차 터치가 Hover/Preview 효과다.
- 같은 대상을 한 번 더 터치하면 실제 Click/Execute로 처리한다.
- 예외: 드롭다운, 입력창은 1차 터치로 바로 동작한다.

[X 버튼 규칙]
- X 버튼은 두껍지 않고 심플한 두 줄 형태를 사용한다.
- PC Hover 시 X가 휘리리릭 도는 느낌으로 회전한다.
- Mobile에서는 1차 터치가 회전 Preview, 2차 터치가 닫기다.

[클래스 최초 진입 게이트 규칙 / 20260615_13]
- 클래스 미선택 상태의 첫 진입 화면에서는 중앙 안내창을 우선 노출한다.
- 이 상태에서는 탑바 우측 클래스 선택 버튼을 숨긴다.
- 중앙 안내창의 클래스 선택 버튼은 기존 classSelector.js의 선택 로직을 호출만 한다.
- 실제 클래스 선택 로직은 복제하지 않는다.
- 클래스 선택이 완료되면 중앙 안내창은 사라지고 탑바 우측 클래스 변경 버튼이 표시된다.
- 이후 다른 클래스로 변경할 때는 탑바 우측 버튼을 사용한다.
- 중앙 안내창 관련 로직은 classEntryGate.js에만 둔다.
- 중앙 안내창 관련 CSS는 class-entry-gate.css에만 둔다.

[파일 책임]
- js/classEntryGate.js: 최초 진입 안내, 탑바 클래스 버튼 숨김/표시 제어.
- css/components/class-entry-gate.css: 중앙 안내창 시각 효과와 닫기 버튼 반응.
- js/classSelector.js: 실제 클래스 선택 쇼케이스와 선택 확정 로직.

[클래스 최초 진입 게이트 보완 / 20260615_14]
- 중앙 클래스 선택창은 페이지 퍼스널컬러인 화이트를 기준으로 유지한다.
- 중앙 클래스 선택창 자체는 과도하게 둥글게 만들지 않고 살짝만 둥근 고급 카드 형태를 사용한다.
- 중앙 클래스 선택 버튼은 둥글둥글한 버튼 감성을 유지한다.
- 중앙 클래스 선택창 테두리 효과는 중심 회전 레이어를 금지하고, EFFECT_FINAL 계열의 외곽 혜성 테두리 방식을 사용한다.
- 닫기 X 버튼은 PC Hover / Mobile 1Tap Preview 시 720도 감속 회전한다.
- 닫기 X 버튼은 지금 당장 닫기 외 역할이 제한적이더라도, 향후 키노조인포 연결이나 다른 링크 확장을 고려하여 제거하지 않는다.

[260615_15] Button System 보강
- ARCANA 버튼을 NAV BUTTON / ACTION BUTTON / SELECT BUTTON으로 분류한다.
- ACTION/NAV 버튼은 arcana-button-system.css / arcana-button-system.js에서 통합 관리한다.
- SELECT BUTTON은 통합 대상에서 제외한다.
- 모바일 1Tap/2Tap 규칙은 ACTION/NAV 버튼에만 우선 적용한다.
- 드롭다운, 입력창, 액티브 스킬 버튼, 클래스 카드, 아르카나 슬롯은 기존 선택 시스템을 유지한다.
