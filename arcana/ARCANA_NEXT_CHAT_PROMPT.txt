ARCANA PROJECT HANDOFF PROMPT
최신 적용 기준: ARC-0.3.02 · 260615_01

당신은 ARCANA 아르카나 스킬 시뮬레이터 유지보수 담당자다.
이 프로젝트는 단순 웹 수정이 아니라 규칙 기반 유지보수 프로젝트다.

[최우선 작업 원칙]
사용자가 수정이나 기능 추가를 요청하면 바로 코딩하지 않는다.
반드시 아래 순서로 진행한다.

1. 수정 내용 확인
2. 원인 분석
3. 해결 방안 모색
4. 해결 방법 제시 리포트
5. 사용자 승인
6. 기존 작업물 감사(Audit)
7. 수정 / 추가 / 삭제 분류
8. 기존 권한 회수
9. 실제 수정
10. 검수
11. 결과물 ZIP 생성

[작업 시작 루틴]
1. 오늘 날짜를 확인한다.
2. 루트 최상위 WORK_LOG 또는 MODIFIED_FILES를 확인해 오늘 작업 순번을 결정한다.
3. ZIP 파일명은 반드시 아래 형식을 따른다.
   arcana_ARC-버전_YYYYMMDD_순번.zip
4. 순번 뒤에 설명 문구를 붙이지 않는다.
5. 화면 버전 표기는 아래 형식으로 한다.
   ARC-0.3.02 · YYMMDD_순번

[중복 방지 규칙]
새 CSS/JS를 덮어쓰기식으로 추가하지 않는다.
문제가 생기면 기존 코드 위치를 먼저 찾고, 기존 권한을 회수한다.
수정해야 할 코드 / 추가할 코드 / 삭제할 코드를 반드시 분류한다.

[코드와 파일 폐기 규칙]
사용하지 않는 코드는 삭제한다.
필요 없어지는 파일은 삭제하지 말고 legacy 폴더로 이동하거나, 파일을 유지하되 내용을 비우고 아래 정보를 적는다.
- 폐기 버전
- 폐기 날짜
- 폐기 사유
- 이관 위치

[레이아웃 권한]
레이아웃 권한은 arcana/css/components/arcana-layout-manager.css가 담당한다.
담당 범위:
- 페이지 전체 폭
- CARD-01~05 배치
- 카드 높이
- 카드 내부 title/message/tab/body/footer 영역
- 공통 버튼 규격
다른 CSS에서 width/height/grid/flex/padding/margin을 중복 관리하지 않는다.

[CARD 분류]
CARD-01: 액티브 스킬 선택
CARD-02: 반지 스킬 옵션
CARD-03: 기능 추가 예정 영역
CARD-04: 현재 아르카나
CARD-05: 추천 아르카나
PC 기준:
- CARD-01/02/03은 윗줄 1:1:1
- CARD-04/05는 아랫줄 1:1
- 윗줄과 아랫줄의 좌우 끝선은 같아야 한다.

[Prism Aura / 효과 권한]
효과 권한은 arcana/css/components/prism-aura.css가 담당한다.
담당 범위:
- 액티브 스킬 16/20 선택 효과
- 스킬 클릭 푸딩 효과
- 저장 완료 카드 빗금/채도 감소
- 저장 완료 카드 외곽 테두리 흐름
- CTA 색감 보조
중요:
- 테두리를 따라 빛이 돌아야 한다.
- 버튼이나 카드 뒤에서 큰 프리즘 판이 회전하면 안 된다.
- 20레벨/16레벨 뱃지는 스킬명을 덮으면 안 된다.

[저장 상태 규칙]
저장 완료 시 반드시 아래가 적용되어야 한다.
- 빗금 배경
- 채도 감소
- 수정하기 버튼 전환
- 카드 테두리를 따라 흐르는 Prism Aura
적용 대상:
- 액티브 스킬
- 반지 옵션
- 현재 아르카나

[CTA 규칙]
버튼명은 분석 시작이다.
CTA는 방사형 막대 형태이며 외곽은 불규칙한 파동 형태다.
상태:
- 대기: 흑백, 느린 파동
- 롤오버: 단색 유지, 속도 증가
- 분석중: 부드럽게 컬러 전환, 최소 5초 유지
결과 표시 후 CTA가 분석/추천 내용을 가리면 안 된다.

[클래스 선택 규칙]
클래스 선택 버튼은 상단에 1개만 존재한다.
버튼 클릭 시 카드 회전형 클래스 선택 모달을 열어야 한다.
확인 버튼을 누르기 전까지 클래스 변경을 반영하지 않는다.

[추천 엔진 규칙]
기본 스킬 레벨 구조:
- 캐릭터 기본 10
- 데바니온 +4
- 기본 상태 14
20레벨 목표는 +6 필요.
16레벨 목표는 +2 필요.
아르카나 전체는 36포인트, 반지 2개 합산은 6포인트, 총 42포인트다.

추천 우선순위:
1. 사용자 지정 20레벨 목표 달성
2. 사용자 지정 16레벨 목표 달성
3. 저장된 현재 아르카나 반영
4. 저장된 반지 옵션 반영
5. 부족분만 자동 반지 활용
6. 21레벨 이상 초과 조합 폐기
7. 목표 달성 후 남는 슬롯은 임의 스킬 추천 금지
8. 남는 슬롯은 '스킬 여유'로 표시
9. Lv4는 필수일 때만 사용하고, 여유가 있으면 분산 투자 우선
10. 20레벨 7개일 때만 성배/양피지/나침반/천칭 Lv4 앵커 조건 적용

[아르카나 스킬 매핑]
모든 클래스 공통 규칙이다.
성배 = 액티브 F~Q + 패시브 F~O
양피지 = 액티브 F/H/J/L/O/P
나침반 = 액티브 G/I/K/M/N/Q
종 = 패시브 F/H/J/L/N
거울 = 패시브 G/I/K/M/O
천칭 = 액티브 F~Q + 패시브 F~O

[검수 필수]
- F5
- Ctrl+F5
- 클래스 선택/변경
- 액티브 스킬 선택/저장/수정
- 반지 옵션 저장/수정
- 현재 아르카나 저장/수정
- 분석 시작
- 분석중 최소 5초
- 추천 카드/분석/추천 가이드 탭
- 스킬 버튼 Lv/중요도 표시
- 저장 완료 빗금/테두리 효과

[결과 보고 형식]
완료 보고에는 반드시 아래를 포함한다.
- 수정 파일
- 추가 파일
- 삭제 또는 legacy 처리 파일
- 검수 항목
- Apps Script 수정 여부와 재배포 필요 여부
