ARC-0.2.03

[이번 작업 요약]
- 최초 진입 시 [클래스 선택] 버튼을 누르면 8장의 클래스 카드가 아래에서 위로 올라오고, 원형으로 회전하는 클래스 선택 쇼케이스를 추가했습니다.
- 쇼케이스 하단에 8개 클래스 이름 버튼을 배치하고, 롤오버 시 해당 클래스 카드만 더 높은 위치로 떠오르도록 했습니다.
- 클래스 이름 또는 카드를 클릭하면 선택한 카드만 남고 나머지 7장은 아래로 떨어지듯 사라지는 연출을 추가했습니다.
- 최초 클래스 선택 이후 상단 버튼 문구가 [클래스 변경]으로 바뀌도록 수정했습니다.
- 최초 선택 이후에는 풀 연출을 반복하지 않고, 기존 간략 클래스 선택창으로 변경할 수 있도록 분기했습니다.
- 궁성 버튼이 검성으로 잘못 표시되거나 삭제되는 문제를 막기 위해 클래스 키/이름 매핑과 표시 순서를 정리했습니다.
- 클래스 버튼, 확인/닫기 버튼의 폭과 높이를 정리하고, 클래스 선택창 내부 버튼을 가운데 정렬했습니다.
- 액티브 스킬 선택/반지 옵션/현재 아르카나 영역의 저장/초기화 버튼 그룹을 가운데 정렬했습니다.
- alert와 window.confirm은 사용하지 않고 기존 페이지 내부 확인 모달 방식을 유지했습니다.

[참고]
- 클래스 표시 순서는 수호성, 검성, 살성, 궁성, 마도성, 정령성, 치유성, 호법성입니다.
- 클래스 아이콘은 신규 생성하지 않고 기존 hall-of-fame/assets 경로를 사용합니다.
- 최초 선택 연출은 현재 브라우저 세션 기준으로 첫 클래스 선택 전에만 동작합니다.
- 추천 엔진 로직과 폴드 반응형 프레임은 이번 버전에서 변경하지 않았습니다.
