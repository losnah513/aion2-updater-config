ARCANA BUTTON SYSTEM
Version: ARC-0.3.02 · 260615_15
Created: 2026-06-15

목적
- ARCANA의 일반 버튼 디자인과 인터랙션을 한 곳에서 관리한다.
- 저장/확인/취소/초기화/클래스 변경 등 실행형 버튼을 통일한다.
- 액티브 스킬 버튼처럼 선택형 슬롯은 보호하고 통합 대상에서 제외한다.

버튼 분류

1. NAV BUTTON / 이동 버튼
- 역할: 페이지 이동, 탑바 기능, 모달/창 열기, 메뉴 호출.
- 예시: 클래스 선택/변경 버튼, 탑바 메뉴 버튼, 향후 KINOJO INFO 연결 버튼.
- 대표 클래스: .arcana-class-picker-button

2. ACTION BUTTON / 실행 버튼
- 역할: 저장, 확인, 취소, 초기화, 적용처럼 사용자의 행동을 실행/확정한다.
- 예시: 스킬 선택 저장, 반지 옵션 저장, 보유 아르카나 저장, 확인, 취소, 초기화.
- 대표 클래스: .arcana-btn, .arcana-btn-primary, .arcana-btn-ghost

3. SELECT BUTTON / 선택 버튼
- 역할: 카드나 영역 안에서 값을 선택하거나 토글한다.
- 예시: 액티브 스킬 버튼, 아르카나 선택 슬롯, 클래스 카드, 드롭다운 항목.
- 대표 클래스: .arcana-skill-btn, .arcana-class-card, .arcana-custom-select-item
- 중요: 일반 버튼 시스템 통합 대상이 아니다. 저장/확인 버튼 디자인을 변경해도 선택 버튼이 같이 바뀌면 안 된다.

통합 대상
- .arcana-btn 중 .arcana-wave-cta가 아닌 일반 실행 버튼.
- .arcana-class-picker-button.
- .arcana-entry-gate-close는 아이콘 버튼으로 최소 규칙만 공유한다.

통합 제외 대상
- .arcana-skill-btn
- .arcana-custom-select-button
- .arcana-custom-select-item
- .arcana-class-card
- .arcana-tab-btn
- .arcana-slot
- .arcana-showcase-name-btn
- .arcana-wave-cta

디자인 규칙
- 전체 페이지 퍼스널 컬러는 화이트.
- 기본 버튼은 화이트/블루 계열을 사용하되, 과한 색 면적은 피한다.
- 버튼 크기, 카드 크기, 레이아웃 크기는 각 카드/레이아웃 CSS의 권한이다.
- 버튼 시스템은 색상, 테두리, 롤오버, 클릭감만 담당한다.

인터랙션 규칙
- PC: Hover는 미리보기 반응, Click은 실행 반응.
- Mobile: 1차 터치는 Hover 효과, 2차 터치는 실행 효과.
- 예외: 드롭다운과 입력창은 즉시 조작 가능해야 하므로 1차 터치 실행을 유지한다.
- SELECT BUTTON은 별도 선택 시스템이 담당한다.

구현 파일
- CSS: arcana/css/components/arcana-button-system.css
- JS: arcana/js/components/arcana-button-system.js

유지보수 규칙
- 일반 버튼 효과를 수정할 때는 arcana-button-system.css를 우선 확인한다.
- 모바일 1Tap/2Tap 규칙을 수정할 때는 arcana-button-system.js를 우선 확인한다.
- SELECT BUTTON 효과는 skillSelector / prism-aura / 관련 선택 시스템에서만 수정한다.
- 효과 수정 중 액티브 스킬 버튼 크기/효과가 바뀌면 실패로 판단한다.
