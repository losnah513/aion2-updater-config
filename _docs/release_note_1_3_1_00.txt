KINOJO 1.3.1.00

타이틀
확장프로그램 버전 통일 및 UI 구조 복구

본문
- 버전 체계를 1.3.1.00으로 통일했습니다.
- Chrome manifest 내부 version은 규칙에 맞춰 1.3.1.0으로 유지하고, 표시 버전/version_name/EXT_VERSION/config.json version은 1.3.1.00으로 맞췄습니다.
- GitHub_Pages/config.json의 version, downloadUrl, notice, patchTitle, patchBody를 최신 버전에 맞춰 수정했습니다.
- 액션 버튼 영역의 구 ControlShell 잔재와 레이아웃 충돌을 정리했습니다.
- 조회 시작 버튼은 대기 상태 프리즘, 조회 중 골드 프리즘 효과가 더 잘 드러나도록 정리했습니다.
- Modern 스타일은 패널 외곽만 화이트 유리 느낌으로 유지하고, 카드 내부는 흰색 배경과 진한 텍스트 기준으로 정리했습니다.
- 비밀번호 입력 모달의 슬라이드 위치, 테마 연동, 확인/취소 버튼 크기, 눈 아이콘 보기/숨김 기능을 복구했습니다.
- 000_README_UserGuide.txt는 버전 표기 없이 공식 원본으로 유지했습니다.
