ARC-0.2.03

[이번 작업 요약]
- 클래스 선택 버튼을 탑바 중앙 영역으로 이동하고, 최초 진입 상태에서는 "클래스 선택", 클래스 적용 후에는 "클래스 변경"으로 표시되도록 수정했습니다.
- 최초 클래스 선택 시 아래에서 8장의 클래스 카드가 올라오고, 원형으로 회전하는 쇼케이스 연출을 추가했습니다.
- 클래스 이름 버튼에 마우스를 올리면 해당 클래스 카드만 떠오르고, 클릭하면 선택한 카드만 남고 나머지 카드는 아래로 떨어지듯 사라지도록 구성했습니다.
- 클래스 적용 후 다시 변경할 때는 풀 연출 대신 간략 클래스 변경 모달이 열리도록 분리했습니다.
- 클래스 버튼 배치를 수호성, 검성, 살성, 궁성, 마도성, 정령성, 치유성, 호법성 순서로 고정했습니다.
- 궁성 버튼이 누락되거나 검성으로 잘못 표시되는 상황을 막기 위해 클래스 목록을 정해진 순서와 키 기준으로 재정렬하도록 보강했습니다.
- 클래스 선택 버튼, 클래스 이름 버튼, 확인/닫기 버튼의 폭과 높이를 내용 기준으로 재조정했습니다.
- 액티브 스킬 선택 영역과 반지 스킬 옵션 영역의 저장/초기화 버튼을 좌우 중앙 정렬로 맞췄습니다.
- 기존 키노조 클래스 아이콘 자산만 사용했으며 신규 이미지는 생성하지 않았습니다.

[유지한 규칙]
- alert와 window.confirm은 사용하지 않았습니다.
- 클래스 실제 반영은 확인 버튼을 누른 뒤에만 진행됩니다.
- 저장 데이터가 있는 상태에서 클래스 변경 시 페이지 내부 확인 모달을 사용합니다.
- 클래스 미선택 상태에서는 시뮬레이터 입력 영역을 비활성화합니다.
- 신규 코드 파일은 만들지 않고 기존 classSelector.js와 layout.css 중심으로 수정했습니다.
