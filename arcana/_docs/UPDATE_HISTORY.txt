ARC-0.2.04

[이번 작업 요약]
- 클래스 선택 목록을 서버 응답 순서에 의존하지 않고 수호성, 검성, 살성, 궁성, 마도성, 정령성, 치유성, 호법성 8개 고정 목록으로 렌더링하도록 수정했습니다.
- 궁성(ranger)이 최초 쇼케이스와 클래스 변경 간략 모달에서 누락되는 문제를 수정했습니다.
- 클래스 버튼/카드 선택 상태를 pendingClassKey 단일 상태로 정리하여 검성 선택 후 다른 클래스를 눌러도 검성 활성 상태가 남는 문제를 수정했습니다.
- 클래스 변경 확인 버튼 클릭 시 클래스 목록 창을 먼저 닫고, 전체 배경 블러 + 중앙 로딩 스피너 + 아르카나 스타일 안내문구로 전환하도록 수정했습니다.
- 기존 카드별 개별 로딩 스피너 대신 클래스 로딩 과정에서는 전체 화면 단일 로딩 오버레이를 사용하도록 수정했습니다.
- 최초 진입 상태의 [클래스 선택하기] 버튼을 탑바 중앙 CTA로 강조하고 은은한 숨쉬기 효과를 추가했습니다.
- 최초 클래스 선택 쇼케이스 카드 뒷면에 영문 클래스명을 필기체 계열 스타일로 표시하도록 추가했습니다.
- 모바일에서 Hover → Click 구조가 있는 클래스 선택 쇼케이스는 첫 터치 시 확인 힌트를 띄우고, 같은 항목을 한 번 더 터치하면 선택이 확정되도록 규칙을 반영했습니다.
- 정령성/수호성 alias 데이터가 섞여 들어와도 정규 클래스 키 기준으로 스킬 데이터를 찾을 수 있도록 fallback을 보강했습니다.

[참고]
- 클래스 표시 순서는 수호성, 검성, 살성, 궁성, 마도성, 정령성, 치유성, 호법성입니다.
- 클래스 아이콘은 신규 생성하지 않고 기존 hall-of-fame/assets 경로를 사용합니다.
- 클래스 로딩 문구는 "아르카나가 선택한 클래스의 스킬을 읽고 있어요."로 적용했습니다.
- 모바일 첫 터치 힌트 문구는 "[클래스명] 이 클래스로 진행하시는 거죠? 맞으시면 한 번 더 터치, 다시 선택하시려면 아무 곳이나 터치해주세요."입니다.
- 추천 엔진 로직과 폴드 반응형 프레임은 이번 버전에서 변경하지 않았습니다.
