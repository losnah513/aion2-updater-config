ARC-0.2.02

[이번 작업 요약]
- 클래스 선택창의 검성 중복과 궁성 누락 문제를 수정했습니다.
- 클래스 버튼을 눌러도 선택창이 닫히지 않고, 확인 버튼을 눌렀을 때만 반영되도록 수정했습니다.
- 첫 화면에서 검성 스킬이 바로 보이던 문제를 수정했습니다.
- 클래스 선택 전에는 입력 영역이 비활성화되고, 친근한 안내문구가 보이도록 변경했습니다.
- 클래스 선택창과 현재 클래스 표시 버튼에 기존 키노조 클래스 아이콘을 연결했습니다.
- 클래스 변경 시 카드별 로딩 스피너와 블러 연출이 보이도록 수정했습니다.
- 현재 캐릭터 스킬 레벨 입력을 제거하고 기본 스킬 레벨 10 고정 조건으로 변경했습니다.
- 장비 스킬 옵션을 반지 스킬 옵션으로 변경하고 무기, 가더 항목을 제거했습니다.
- 추천 로직이 각 클래스 시트의 아르카나별 스킬 풀을 기준으로 작동하도록 수정했습니다.
- 아르카나 카드의 실제 성장 규칙을 반영하여, 선택된 스킬은 Lv1부터 시작하고 카드 성장 포인트 5를 분배하도록 변경했습니다.
- 추천 로직은 Lv4 강요를 줄이고, 가능한 한 4개 슬롯을 활용해 제작 부담을 분산하도록 변경했습니다.

[참고]
- 각 클래스 시트의 D1:I1은 아르카나 종류입니다.
- 각 아르카나 이름 아래 열은 해당 아르카나에 등록 가능한 스킬 목록입니다.
- alert와 confirm은 사용하지 않았습니다.
