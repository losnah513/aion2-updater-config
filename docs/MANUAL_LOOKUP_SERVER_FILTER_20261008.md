# 수동 조회 서버명 필터 수정 · SQL531

- 사용자 입력 꾸힉[지켈]의 2026-10-08 14:41 KST 실행은 공식 조회 전 대상0으로 완료됐다. DB Master13에는 기존 이름과 charKey가 있다.
- 원인: v296은 servers=["지켈"]에서 숫자만 추출해 server_id와 비교했다. 이름 입력은 빈 문자열이 되어 대상에서 제외됐다. 과거 안정화 LOG55의 더샷 사례와 같은 경로다.

- 검증/배포/Drive 최종 상태는 안정화 프로젝트 LOG58에 기록한다. 이 수정만으로 꾸힉의 새 이름을 공식 확인했다고 주장하지 않는다.
