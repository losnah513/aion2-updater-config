ARC-0.2.01

[이번 작업 요약]
- 액티브 스킬 선택창과 현재 캐릭터 스킬 레벨 입력 기능을 하나로 통합했습니다.
- 액티브 스킬 버튼을 선택하면 버튼 내부에 레벨 입력칸이 표시되도록 변경했습니다.
- 현재 캐릭터 스킬 레벨 독립 카드는 제거했습니다.
- 액티브 스킬 선택창과 장비 스킬 옵션창을 상단 좌우 배치로 정리했습니다.
- 두 입력창의 폭과 높이를 같은 기준으로 맞췄습니다.
- 남는 공간 확인용으로 기능 추가 예정 영역 카드를 추가했습니다.
- 클래스 버튼 선택 후 드롭다운이 닫히지 않고 확인 버튼을 눌러야 반영되도록 유지했습니다.
- 저장된 정보가 있을 때 클래스를 변경하면 페이지 내부 확인창을 표시하도록 추가했습니다.
- 클래스 변경 시 장비 선택 상태, 추천 아르카나 상태, 저장 잠금 상태가 함께 초기화되도록 수정했습니다.
- 저장 완료 상태에서는 해당 창의 버튼과 입력을 다시 조작하지 못하도록 동작을 보강했습니다.

[유지 규칙]
- 브라우저 기본 알림창은 사용하지 않습니다.
- 창 높이가 문구나 탭 내용 때문에 늘어나지 않도록 유지합니다.
- 버튼 폭과 카드 폭은 고정 기준 안에서만 움직입니다.
- 비슷한 상태 처리 코드는 전용 파일에서 관리합니다.
