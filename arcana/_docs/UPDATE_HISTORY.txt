ARC-0.1.00 아르카나 수정사항 01

[이번 작업 요약]
- 전체 페이지 폭을 줄여 한 화면에 더 많은 정보가 들어오도록 조정했습니다.
- 카드 뒤 배경색을 제거하고 전체 화면을 화이트 기준으로 다시 정리했습니다.
- 카드 테두리의 둥근 정도를 더 줄였습니다.
- 각 항목 카드의 제목 영역과 본문 영역을 분리했습니다.
- 액티브 스킬 선택 영역 이름을 변경했습니다.
- 액티브 스킬 선택 개수 안내를 새창이 아닌 제목 오른쪽 문구로 표시하도록 변경했습니다.
- 7개를 모두 선택하면 최대치 선택 문구가 강조되도록 변경했습니다.
- 액티브 스킬 버튼 폭을 가장 긴 스킬명 기준으로 자동 조정하도록 변경했습니다.
- 현재 아르카나와 추천 아르카나를 별개의 항목 카드로 분리했습니다.
- 현재 아르카나 저장 후 추천 아르카나 영역이 잠깐 로딩된 뒤 강조되어 보이도록 변경했습니다.
- 추천 아르카나 로딩 연출에 첨부한 로딩 이미지를 적용했습니다.
- 초기화 버튼 강조 효과를 테두리를 따라 빛이 도는 방식으로 다시 제작했습니다.

[참고]
- 버전명은 ARC-0.1.00으로 유지했습니다.
- 이번 작업은 화면 디자인과 화면 동작 정리 중심입니다.
- Apps Script 소스 코드는 이번 작업에서 수정하지 않았습니다.
- 파일명, 함수명, 시트명 외 설명 문구는 한글로 작성합니다.
